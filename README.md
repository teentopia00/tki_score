# 스트레스 패턴 진단 앱

스트레스의 6가지 패턴을 자기 진단하고, 결과에 맞는 실천 행동을 제안하는 정적 웹앱입니다.

## 기능

- 26개 문항 기반 자가 진단
- 기회/위협, 침착/역동 축 계산
- 등대형, 연금술사형, 소방수형, 스토익형, 외교관형, 컨테이너형 결과 제공
- 유형별 강점, 주의점, 오늘 바로 할 행동 제안
- 결과 복사 및 브라우저 저장 기능

## 실행

GitHub Pages 또는 `index.html` 파일을 브라우저로 열어 사용할 수 있습니다.

## 참고

이 앱은 사용자가 제공한 `The Power of Knowing Your Stress Patterns` 관련 정리 텍스트를 바탕으로 만든 자기이해 도구입니다. 의료적 진단이나 치료를 대체하지 않습니다.
